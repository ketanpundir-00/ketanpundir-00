## Featured projects

### ClearLedger ([clearledger.co.in](https://clearledger.co.in))
A B2B SaaS for Indian accounting workflows. Upload messy Excel, CSV, or PDF files and get clean, import-ready output.

- Bank statement auto-detect and parsing (HDFC, SBI, ICICI, Axis, Kotak, PNB, Bank of Baroda, Canara)
- Bank reconciliation with narration standardization (UPI, IMPS, NACH, NEFT)
- GST 2B reconciliation with fuzzy matching
- GSTIN and PAN format validation
- Payslip generation, Tally XML and Zoho Books export
- Handles large files: PDF page limits, timeouts, and row limits to fail early and safely

**Stack:** Next.js, FastAPI (Python), Supabase (auth, database, RLS), Render, Vercel, Sentry, GA4

### GST RAG Chatbot
A question-answering chatbot over official public GST documents (FAQs and guidance PDFs), built to give answers with the source page.

- PDF ingestion that chunks documents Q&A-wise (1,000+ chunks)
- BM25 retrieval with light stemming and query expansion
- Answers generated with the Gemini API, with a search-only fallback, answer caching, and per-IP daily limits
- FastAPI backend, already added as an endpoint in the ClearLedger backend

**Stack:** Python, FastAPI, BM25, Gemini API
